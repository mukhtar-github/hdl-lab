Where the numbers come from

Each run's instruction count is the per-byte cost times 12,012 bytes (1,001 CRCs of 12 bytes), plus about 18 instructions per CRC spent outside the byte loop.

The window is the first byte of the reference CRC: from its first lbu, which loads the frame's first byte, to the next one. Regenerate the page with make -C bench/rv32 anatomy.

make -C bench/rv32 run CRC_IMPL=bitwise                 # the bitwise definition
make -C bench/rv32 run CRC_IMPL=bitwise ALGOFLAGS=      # GCC's substituted table
make -C bench/rv32 run                                  # the stated table (reference)
spike -l --log-commits --log=trace.log --isa=rv32im build/<hash>/crc_itu_ref.elf
