## Session — 2026-10-02: the reference decoder's harness

**Did:**
- **`bench/decoder`, the harness that `0014` specifies:** step 2 of the decoder's four.
  - The stimulus is linked in last. Two stimuli give two images, but one decoder image.
  - Before the window, the harness refuses what `container.unpack` refuses.
  - The window holds the chunk walk, the decoder and the end of input, counted in 64 bits.
  - Records go to a buffer as words, with fields in any order. After the window, a stable counting
    sort and a formatter write them out through `SYS_write`. The last line repeats the count.
- **Two test decoders.** `expect.py` predicts all 496 lines of `stub.c` from the coverage stimulus.
  `format_test.c` writes ten records whose text I wrote out by hand before the first run.
- **`make mutate` breaks the harness 16 ways,** and something caught all 16. Captured as
  `20261002T143128Z-decoder-harness`.

**Broke / didn't work:**
- **A broken chunk walk hung Spike for more than 10 minutes.** It made a misaligned load. With no
  trap handler, the trap went to address 0, and I stopped Spike by hand. The harness now ends the
  run on any trap, and prints `mcause` and `mepc`.
- **`csrw` would not assemble with `-march=rv32im`.** CSR instructions need Zicsr, though
  `rdinstret` assembles without it. `.option arch, +zicsr` enables it for those lines only, so the
  compiler's ISA string is unchanged.
- **My first trap handler read `mtval`.** `0009` leaves `mtval` open, and by `0009`'s rule anything
  the harness reads becomes a requirement on the core. The handler now reads `mcause` and `mepc`
  only.
- **One corrupted stimulus tested the wrong thing.** With 12 connections there is no padding after
  the table, so my "padding" byte was a protocol code. A 13-connection stimulus tests the padding
  now.
- **Python buffered the scratch mutation script's output,** so its log was empty while Spike hung.
  `mutate.py` flushes each line, and limits each run to 180 s.

**Confused about:**
- **Whether the record buffer is the right hand-off.** A 32-bit field costs two stores. A fixed
  layout for each frame type would cost fewer. This choice sets part of the count, and no
  measurement has compared the two.
- **A hang outside `mutate.py` has no time limit.** An infinite loop that never traps would still
  hang `make check`. macOS has no `timeout` command, and Spike 1.1.0's help lists no option that
  limits instructions.
